# ADR-0013：自动阶段进度与资料操作浮窗

日期：2026-10-02。状态：用户已明确决定，代码实现及本轮范围内验证完成；负责人体验 NOT RUN。

## 最新用户决定

“替换本阶段主线，资料偏好，补充本单元资料”各自做成一个按钮，点击进入对应浮窗。移除“本次出现位置的学习进度”。学习者只关注阶段层级，进度只区分已完成、未完成；知识节点不标学习状态。完成给定阶段总结与该阶段实践任务（如果有实践）即为阶段已完成，没做或没做完就是未完成。

## 业务规则

新增只读的阶段完成投影：`StageWorkspaceView.completion` 返回 `completed / incomplete`、总结完成与实践完成数量；工作区返回完成阶段数与总阶段数。

总结完成以当前 `project_id + plan_id + stage_id` 的已保存、非空**阶段总结**为准，无需 AI 反馈或额外总结审批。旧明确 unit_id 的单元总结保留历史，不代替整阶段总结。

实践完成复用现有实际成果验收的 `accepted` 记录，绑定同一项目、路线、阶段、任务；方案 / Prompt 保存、模型建议、仅提交成果不等于实践完成。本轮不新增实践验收步骤。全部给定任务完成并且阶段总结已完成，阶段才为已完成；没有实践任务时只要求总结。任务全局 accepted 或旧路线 accepted 不自动完成新路线的任务出现位置。

阶段状态由读取投影自动计算，保存总结与实践完成后刷新工作区。不能手动勾选阶段完成，也不新增阶段通关门槛或阻止继续学习。

## 历史、核验与界面

本决定替代 ADR-0012 中面向学习者展示单元自述进度的安排。旧 UnitProgress、Exposure、六态知识核验及历史仍保留内部契约与数据；新阶段完成不向这些历史表写入模拟进度，不推断知识 VERIFIED，也不把阅读或来源核验当阶段完成。

阶段侧栏、工作台、学习路径统一显示阶段状态和阶段完成数。知识节点与学习单元只显示内容，不展示学习状态；资料来源核验标记仍在资料列表如实保留。

三个资料浮窗复用原业务组件，原预览、明确确认、版本保护、偏好范围、搜索外发提示及候选核验状态保持有效。关闭浮窗再打开保留本次页面中的未保存输入与待处理请求；切换阶段/学习单元按原位置隔离。浮窗使用原生 dialog 模态语义、标题、关闭及 Escape、焦点管理和可滚动正文，窄屏不溢出。

本轮没有新 migration、收费调用或私人路线批准。验收由[本轮报告](../acceptance/frontend-learning-revision-2026-10-02.md)承接，完整产品仍须其余 V2 门禁和负责人验收。
