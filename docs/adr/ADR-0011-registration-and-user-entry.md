# ADR-0011：注册密码与正常用户入口

日期：2026-10-02。状态：用户明确决定，已实现。

用户最新明确要求注册密码为6–12位，并报告当前15–128提示、注册被成果验收入口403拒绝、旧账号无法登录。本决定只替代V2指导§3的新注册密码默认范围；原指导文档和ADR-0010保持原文用于溯源。

新注册按Unicode码点计数6–12，UI、Domain和RegistrationRequest一致；不截断、不规范化密码、不阻止粘贴，不强制字符混合。旧账号登录校验继续1–128，再由现有Argon2id散列判定，不用新注册范围限制已存密码。中文用户名规则、散列、限流、Cookie、CSRF及RLS保留。

用户入口必须读取本机.env配置的正常产品数据库，不能连接临时验收wrapper。正常默认本地API端口8022、前端5175，避免占用既有独立RAG的8000。验收服务仍使用原隔离库/8021及其原保护规则，不移除保护、不复制账号到验收库。

注册/登录修复与模型消费分开。正常API启动不自动启动Worker；模型调用、旧Run恢复、草案批准、外部搜索依原授权和额度执行。不存在启动即恢复旧付费任务的行为。

验证与当前运行证据见[注册入口报告](../acceptance/F01-registration-entry-2026-10-02.md)。该修复不代表F01完整项目管理或F01–F18整体完成。
