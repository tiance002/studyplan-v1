# 用户自带模型配置：OpenAI 兼容接口

## 用户要求与范围

云端用户自行填写 Base URL、模型名、API Key；当前软件仅支持 OpenAI 兼容 `/chat/completions` 格式。保留当前本机环境变量配置。此设计不新增其他模型协议、登录注册系统、云部署或自动试用调用。

现有认证接口只提供本地单用户会话，真正多用户云端发布仍需要后续认证系统；设置功能必须依赖已有服务端 AuthContext，不能接受请求体中的 actor_id。

## 方案选择

建议使用服务端持久化的个人设置：浏览器提交一次 API Key，服务端加密保存并调用模型，前端 GET 只返回 Base URL、模型、版本和 has_api_key。页面刷新后可继续使用，用户之间隔离。浏览器直接调用会暴露密钥并受供应商 CORS 限制；只保存浏览器 session 的方案则不能支持跨设备及服务端工作流恢复。

## 数据与接口

每个 actor 一份当前设置，保存产生不可变配置修订。Base URL、model_id 和加密 API Key 属于同一修订；独立服务端加密主密钥放部署 secret，不放 PG、前端或 checkpoint。使用成熟的认证加密库，不自行设计密码算法。主密钥缺失时拒绝保存和使用个人设置，不降级为明文。

GET `/api/v1/model-settings` 返回公开元数据，不回显完整或部分密钥；PUT 携带当前 version 进行 CAS，旧窗口返回 409。更新已有设置时空白 API Key 表示保留当前密钥，第一次保存必须有 Key；清除操作禁用当前设置，不影响既有正式路线。历史配置只用于运行身份核对，不允许因已删除凭据而自动重发。

前端“模型设置”入口包含 Base URL、模型名称、密码输入框、保存/清除、当前版本及已保存状态。明确显示“仅支持 OpenAI 兼容 API”和“保存不发起模型调用”。密钥不写 localStorage，不出现在错误、日志、OpenAPI 示例或 GET 响应；保存成功后清空输入框。未配置时生成按钮引导填写，不能静默用 Fake。

## 接入生成和重放

每次 Run 创建时固定所用个人配置修订，并记录在业务 PG 中；该 Run 的纲要、结构、实践及修复使用同一配置对象。不得修改共享 PlanService 的 provider，避免并发用户串配置。模型调用账本的 fingerprint 包含配置修订和提示词版本；保存设置不会改变既有 run/attempt 的身份。

未设置个人配置时可继续使用部署端默认配置，但 UI 必须明确显示当前使用默认模型；默认也不可用时返回明确的未配置状态。批准/取消仅完成业务事务和 checkpoint，不重新请求模型，因此个人配置更换不会改变历史发布重放。

## 云端 URL 边界

自定义 URL 由服务端发请求。只接受 HTTPS、非内嵌凭据、无 query/fragment、默认 443 端口；禁止重定向及私网、环回、链路本地、云 metadata 地址。部署管理员配置允许的服务商主机名，初始包含 api.openai.com / api.deepseek.com；用户仍填写完整 base URL，其他兼容服务商须由管理员加入允许名单。解析时检查公开 IP，生产出口网络还需阻断私网/metadata，避免 DNS 变化绕过访问边界。主机校验必须发生在发送 Authorization 之前。

## 实现位置与验证

复用现有 FastAPI、PG、httpx、StateGraph，不引入新框架。新增 actor 隔离的设置迁移/仓储、应用服务及端口、路由、每 Run provider 工厂，接入当前前端。加密库是基础依赖；部署配置提供主密钥和允许名单。

必要验证：两个 actor 互不可读写；PG 无明文密钥；GET/错误无密钥；修改版本冲突；禁止危险 URL；两个并发 Run 不串模型配置；设置变化不改既有 run/attempt；已配置模型经真实 HTTP/PG/StateGraph 生成到确认回读；浏览器设置保存、刷新、清除与生成流程。
