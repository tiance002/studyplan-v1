# V1 产品范围

规格冻结：2026-10-01 / S0。上位输入：[用户补充原文](supplements/studyplan_requirements_design_supplement_2026-10-01.md)。状态为设计决策生效，功能完成度见 [Gap Analysis](../reviews/2026-10-01-v1-gap-analysis.md)。

## 产品目标

面向个人本地使用，帮助零基础用户完成目标→知识结构→路径→资料→学习→总结→反馈→实践→成果→证据验收→进度→路径调整。首个完整领域是 Agent 应用开发，以可持续演化的主项目组织实践。课程需要解释为什么这样设计、替代方案及场景取舍。

默认从零规划；用户可跳过、返回、改变资源偏好和提出扩展主题。不建设入门能力测评、mastery score 或自动能力评级。

## V1 交付边界

- 稳定知识连接点、不可变计划版本、用户确认的结构变更。
- 可核对的资源索引与动态视频/文字/语言偏好。
- 节点和计划版本绑定的 LearningSession、原始总结、AI Feedback、历史恢复。
- 同一主项目的阶段任务、用户先提出实现思路、AI 评审、指定版本导出、外部 Codex/IDE 实施。
- 证据、验收结论和知识学习状态分离；可检查证据支持 VERIFIED。
- 有限 LangGraph、明确错误、隐私/外发/预算边界、显式付费验收授权。

V1 不交付登录注册、多用户 SaaS、复杂 RBAC、团队协作、MCP/Sandbox/Skills Runtime、工具市场、多 Agent 自组织、GraphRAG、复杂图谱推理、自动互联网爬虫、高并发专项和商业模板市场。它们进入 V2 或更后期 backlog。RAG、MCP、Memory 等可以是课程主题；这不授权产品接入这些运行能力。

## 本地身份与既有数据

按 [ADR-0007](../adr/ADR-0007-v1-local-user-scope.md) 改为服务端固定本地 actor 的入口，复用已有配置能力。入口切换尚待 M1.1 实现；当前代码仍要求浏览器登录。原 actor、Project、模型凭据、Run 和历史数据保留。不以客户端传入 actor 或关闭项目约束实现单用户模式。

已有 RLS、数据库角色、幂等、队列、checkpoint 和 Provider ledger 服务数据正确性，继续复用；本轮不增加平台认证能力，也不为范围调整删除历史迁移。

## V2 扩展点

保留 Ports、明确 scope、不可变版本与 DomainPack；需要真实产品场景时再引入工具运行、云端身份或模板共享。私人学习内容用于公共模板改进须用户单独同意。

## 成功标准

[八个真实场景与完整闭环](EVALUATION_ACCEPTANCE.md) 通过，P0/P1 解决，负责人确认 P2/P3 延期，才是 V1 可交付。测试数量、Agent 数量和生成成功不能替代这一结论。
