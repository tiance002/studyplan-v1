## 运行规则

Fake LLM 只在开发模式显式启用，使用预设 Agent 开发场景，资源是未核验搜索建议，没有云模型调用或假 URL。真实模型保留原配置路线，付费 dispatch_unknown 保持待核对，禁止自动重发。

同步规划抛异常由已有服务落 failed。若进程中断，queued / running 的 updated_at 超过预算，在下一次读取 Run 时使用 CAS 转为 reconciliation_required。预算至少 30 分钟，或 `3 × (最大修复次数 + 1) × 单次模型超时 + 300 秒`，取较大值；waiting_user 和成功终态不超时。该机制不自动恢复模型执行，不是后台 worker。
